# prompt-engineering-toolkit

全场景提示词工程工作台：标准化提示词生成、8阶段流程管控、7大AI工具适配、执行三纪律兜底。

## 核心能力

- **五要素提示词结构**：角色身份 → 任务目标 → 上下文背景 → 约束规则 → 输出要求
- **8阶段全流程管控**：需求判定 → 流程拆解 → 初稿 → 缺陷评审 → 适配优化 → 跨工具适配 → 打包 → 归档
- **执行三纪律**：长任务必拆 / 每关必测 / 10秒熔断
- **7大工具适配**：GitHub Copilot、Claude Code、ChatGPT、Kimi、Trace Code、豆包、通义千问
- **五大场景模板**：学术论文、AI程序开发、AI网页制作、游戏开发、AI Demo

## 执行三纪律

1. **长任务必拆**：超过3步必须拆成子任务清单，逐个执行
2. **每关必测**：每完成一个阶段必须验证，通过才继续
3. **10秒熔断**：单步超时立即交付已完成部分并反馈报错
